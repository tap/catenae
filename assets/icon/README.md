# The catenae icon

| File | Use |
|---|---|
| `catenae-icon-square.svg` | The icon, for 128 px and larger |
| `catenae-icon-small-square.svg` | A heavier drawing for 64 px and smaller |
| `png/catenae-icon-{128,256,512,1024}.png` | Rasters of the icon |
| `png/catenae-icon-small-{16,32,48,64}.png` | Rasters of the small drawing |
| `favicon.ico` | 16, 32 and 48 px, for the documentation site |
| `preview.png` | Both drawings at their sizes, on light and dark |
| `src/gen.py`, `src/square.py` | The scripts the drawings were generated with, as supplied |

The colour is `#1E9A98`.
