# catenae

**C**hainable **A**udio **T**ransforms for **E**mbedded, **N**ative & **A**ccelerated **E**nvironments.

A C++17 library of audio processing *stages*, the *chain* that composes them, and the
*junctions* that join chains across threads and clocks.

**Status: planning.** Nothing is built yet. The design, its decisions and the milestones are
in [`PLAN.md`](PLAN.md).

To be released under the MIT license; the license file arrives with the first code.
